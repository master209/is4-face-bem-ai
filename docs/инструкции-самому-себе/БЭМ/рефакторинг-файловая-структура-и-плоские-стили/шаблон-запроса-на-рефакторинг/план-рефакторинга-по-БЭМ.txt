ЗАПРОС НА РЕФАКТОРИНГ БЭМ-БЛОКА ПО МЕТОДОЛОГИИ

Задача: Преобразовать БЭМ-блок "Super" в соответствии с методологией БЭМ

Цели рефакторинга:
1. Организовать правильную файловую структуру БЭМ для блока "Super"
2. Заменить каскадные стили на плоские селекторы БЭМ
3. Создать отдельные компоненты для всех БЭМ-элементов блока
4. Использовать cn() для безопасной генерации CSS-классов

Требования:
- Пользовательский интерфейс НЕ ДОЛЖЕН измениться
- Вся функциональность должна быть сохранена
- Код должен компилироваться без ошибок
- Элементы НЕ экспортировать наружу блока (только внутреннее использование)

Инструменты и документация:
- Следовать инструкциям в: /docs/инструкции-самому-себе/БЭМ/рефакторинг-файловая-структура-и-плоские-стили/README.md
- Использовать примеры из: examples/tab-refactoring.md
- Шаблоны компонентов: templates/
- Правила БЭМ из: /docs/BEM/

Этапы выполнения:
1. Проанализировать текущий код блока "Super"
2. Создать новую БЭМ-структуру файлов и папок
3. Разбить стили на отдельные файлы элементов и модификаторов
4. Создать .tsx компоненты для каждого элемента
5. Рефакторить главный компонент блока
6. Протестировать и обновить документацию

Ожидаемый результат:
- Полностью БЭМ-совместимый блок "Super"
- Читаемый, поддерживаемый и переиспользуемый код
- Самодокументируемая архитектура для будущих разработчиков
