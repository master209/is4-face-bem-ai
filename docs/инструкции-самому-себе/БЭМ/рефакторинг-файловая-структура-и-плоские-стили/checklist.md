# ЧЕК-ЛИСТ: Проверка рефакторинга БЭМ-блока

## 📋 Перед началом
- [ ] Создан бэкап исходных файлов
- [ ] Проанализирована HTML-структура
- [ ] Найдены все каскады в стилях
- [ ] Определены элементы и модификаторы

## 🏗️ Файловая структура
- [ ] Созданы папки для всех элементов (`ElementName/`)
- [ ] Созданы папки для модификаторов элементов (`ElementName/_modifierName/`)
- [ ] Созданы папки для модификаторов блоков (`_modifierName/`)
- [ ] Главный файл блока импортирует все элементы
- [ ] Пути импортов корректны

## 🎨 Стили
- [ ] Каждый БЭМ-класс имеет плоский селектор
- [ ] Убраны каскады между элементами одного блока
- [ ] Модификаторы импортированы в базовые файлы
- [ ] Дефолтные состояния в базовых классах (убраны `_inactive`)
- [ ] Псевдо-селекторы только внутри одного БЭМ-класса

## 💻 Код компонентов
- [ ] Обновлены `className` в JSX
- [ ] Убраны тернарные операторы с `'inactive'`
- [ ] Добавлены новые БЭМ-классы для замены каскадов
- [ ] Элементы находятся внутри блоков (добавлены обертки `<div className="Block">`)
- [ ] Проверить все места использования блока

## ⚙️ Компиляция и тестирование
- [ ] SCSS компилируется без ошибок
- [ ] Нет ошибок линтера
- [ ] Сервер запускается успешно
- [ ] Внешний вид не изменился
- [ ] Функциональность сохранена
- [ ] Все вкладки/элементы работают корректно

## 📚 Документация
- [ ] Обновлена инструкция для себя
- [ ] Добавлен пример рефакторинга
- [ ] Задокументированы проблемы и решения
- [ ] Создан чек-лист для будущих рефакторингов

## 🎯 Финальная проверка
- [ ] Код соответствует принципам БЭМ
- [ ] Структура удобна для поддержки
- [ ] Можно переиспользовать в других местах
- [ ] Готово к следующему рефакторингу
